## 🤝 Contributing

Want to contribute? Good — but don’t expect bagunça.

1. Fork the repository
2. Create a branch (`feature/your-idea`)
3. Write clean and understandable code
4. Open a Pull Request

### Basic rules:

* Keep code readable and organized
* Follow existing patterns
* Don’t break what already works
